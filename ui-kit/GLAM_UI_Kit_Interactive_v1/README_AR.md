# GLAM UI Kit Interactive v1

## الحالة

- الهوية: مثبتة وفق `GLAM_Identity_Lock_v1_AR.md`.
- الألوان والمقاسات: مأخوذة من `GLAM_Design_Tokens_v1.json`.
- خط الواجهات: Readex Pro بأوزان 400 و500 و600 و700؛ أما كلمة Glam في الشعار فتستخدم أصل الـ wordmark المعتمد.
- تصحيح الشعار: التوتي `#5A1835` هو لون الشعار المعتمد، وشكل الحروف مأخوذ من مرجع كلمة Glam اللافندر. اللافندر مرجع شكلي فقط وليس لونًا للهوية.
- الاتجاه: العربية RTL أولًا، مع دعم الإنجليزية LTR.
- النطاق الحالي: الحزمة التفاعلية الكاملة، وتشمل لوحة الهوية والمكوّنات، تجربة العميلة من الاكتشاف إلى الحجز والتقييم، رحلة الصالون من الانضمام والاعتماد إلى التشغيل، وإدارة المنصة.
- Hero تطبيق العميلة: الصورة تبقى ظاهرة في مساحة مستقلة يسارًا، والنص والبحث داخل لوحة عاجية يمينًا؛ لا يوضع النص فوق الصورة.
- قاعدة إلزامية: ملف الهوية والتوكنات هما المرجع الحاكم؛ لا تُستخدم ألوان أو خطوط مستخرجة من صور المعاينات، ولا يُستبدل أصل الشعار بخط نصي.

## فتح النسخة محليًا

افتح `dist/index.html` في المتصفح. الصفحة لا تحتاج تثبيت حزم أو خادم خلفي.

## التفاعلات المتاحة

- التنقل بين الهوية والمكوّنات وتطبيق العميلة.
- التبديل بين عرض سطح المكتب والجوال.
- التبديل بين العربية والإنجليزية.
- تجربة اختيار الموعد والمفضلة والتنبيهات.
- البحث والتصفية حسب نوع الخدمة في C-02.
- الانتقال من نتائج الاكتشاف والخريطة إلى صفحة الصالون C-03 واختيار الخدمة.
- تجربة C-04 لاختيار اليوم عبر شريط زمني مختصر، ثم اقتراح أقرب 3 أوقات مع خيار فتح بقية الأوقات عند الحاجة.
- فتح قسم «رحلة الصالون» لمراجعة بيانات المنشأة والاعتماد قبل النشر.
- فتح قسم «لوحة الصالون» لمراجعة التشغيل اليومي، التقويم، العميلات وتفضيلات الزيارة، الخدمات والعروض، الفريق، المخزون، المالية، التقارير، التسويق ولوحة المحتوى، التقييمات، الإعدادات والاشتراكات.
- فتح قسم «إدارة Glam» لمراجعة الاعتمادات، سجل التدقيق وقواعد الموافقة البشرية.
- فتح قسم «كل الصفحات» لمراجعة الحجز، الحساب، الحجوزات، الإشعارات، صفحة الخبيرة، إدارة الصالون، التقويم، الخدمات، الفريق، الورديات، التوفر، قائمة الانتظار، التقارير، الانضمام، إدارة المنصة، الهوية والمساعدة.
- جميع البيانات في النسخة التفاعلية تجريبية للمراجعة، ولا تُنشئ حجوزات أو مدفوعات فعلية.
